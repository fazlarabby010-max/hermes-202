Complete the setup for the `google-workspace` skill (which handles OAuth2 authentication).\n   - This skill expects `google_token.json` and `google_client_secret.json` in `~/.hermes/`.\n   - Run `hermes skill run google-workspace --check` to verify authentication.\n\n2. Enable the required APIs in your Google Cloud Project:\n   - Gmail API\n   - Google Drive API\n   - Go to https://console.cloud.google.com/apis/library and enable both APIs for your project.\n\n## Installation\n\nThe skill is already installed at `~/.hermes/skills/google-integration-workflow/`.\n\n## Usage\n\nThe workflow is accessible via the Python module `hermes_integration.google_integration.workflow`.\n\n### From Python\n\n```python\nfrom hermes_integration.google_integration.workflow import create_email_with_attachment\n\nresult = create_email_with_attachment(\n    recipient=\"user@example.com\",\n    subject=\"Meeting Notes\",\n    body=\"Please find the meeting notes attached.\",\n    drive_file_name=\"meeting_notes.txt\"\n)\n\nif result.get(\"status\" == \"success\"):\n    print(f\"Draft created: {result['draft_link']}\")\nelse:\n    print(f\"Error: {result['error']}\")\n```\n\n### From the Command Line\n\nYou can also run the workflow as a script:\n\n```bash\ncd ~/.hermes/skills/google-integration-workflow/\npython -c \"\nimport sys\nsys.path.insert(0, '..')\nfrom google_integration.workflow import create_email_with_attachment\nresult = create_email_with_attachment(\n    recipient='user@example.com',\n    subject='Test',\n    body='Test body',\n    drive_file_name='test.txt'\n)\nprint(result)\n\"\n```\n\n## Workflow Details\n\n1. **Search Drive**: Looks for a file by name in Google Drive (optionally within a specific folder).\n2. **Download File**: Downloads the file to a temporary location.\n3. **Create Draft**: Creates a Gmail draft with the file as an attachment.\n4. **Return Link**: Returns the Gmail draft link for the user to review and send manually.\n\n## Error Handling\n\n- If the file is not found in Drive, returns an error message.\n- If the Google APIs are not enabled, returns an API error with instructions to enable them.\n- If authentication fails, prompts the user to re-run the google-workspace setup.\n\n## Security\n\n- The skill uses the existing OAuth2 token from the `google-workspace` skill.\n- No credentials are logged or exposed.\n- Token files (`google_token.json`, `google_client_secret.json`) should be kept secure and are already excluded from Git via `.gitignore`.\n\n##
